# Nöbetçi Eczane - Türkiye

Türkiye'deki nöbetçi eczaneleri bulmanızı sağlayan web uygulaması.

## Özellikler

- 🏥 Güncel nöbetçi eczane bilgileri
- 🌍 81 il desteği
- 📱 Responsive tasarım
- 🌙 Dark/Light tema
- ⚡ Hızlı arama

## Teknolojiler

- Node.js
- Express.js
- EJS Template Engine
- Tailwind CSS
- T.C. Sağlık Bakanlığı API

## Kurulum

```bash
npm install
npm run build
npm start
```

## Geliştirme

```bash
npm run dev
```

## Deployment

Bu proje Vercel'de deploy edilmek üzere yapılandırılmıştır.
